# Consumo de API no oficial del boletin concursal CL (chile)
Esta aplicacion en python se conecta a la pagina del boletin concursal y obtiene los datos en formato json para su manipulación.
Llevo poco tiempo programando con python, interesante la versatilidad que tiene para obtener datos de paginas web e interactuar con ellas. cree la aplicacion porque necesitaba estos datos y no encontre ninguna que realizara esta accion.
